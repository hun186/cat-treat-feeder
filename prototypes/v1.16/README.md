# V1.16：底座前伸與滑塊擠壓間隙改善（試驗版）

這版使用你實測滿意的 V1.15 `slider_tight` **左右／上下軌道配合尺寸**，但重新調整擠壓橫桿，並延長底座前端；尚未完成實物驗收。

| 參數 | 舊 V1.15 | 新 V1.16 |
|---|---:|---:|
| 底板前緣 x | 141 mm | **146 mm** |
| 前端限位器 | 134.5–141 mm | **139.5–146 mm**（6.5mm 長不變） |
| 軌道末端 x | 128 mm | **140 mm**（與限位器重疊 0.5mm） |
| 標準版滑塊側隙 | V1.15 tight 各 0.25 mm | **各 0.25 mm** |
| 上方間隙 | V1.15 tight 0.30 mm | **0.30 mm** |
| 擠壓橫桿到袋子底板間隙 | 2.0 mm | **1.2 mm** |

STL 輸出選項：`slider_print` 是標準 1.2mm；`slider_print_gentle` 是 1.6mm；`slider_print_close` 是 0.9mm **實驗版，不建議先用**；`body_side_print` 為新底座。

測試：本地 OpenSCAD 產生 STL，四個網格（底座、三種滑塊）皆 watertight、單一實體、法線一致、正體積。CGAL 組件交集在 slider 中心 x=17～135 mm 無重疊，x=135.7 mm 受到前擋阻擋。這些測試**沒有驗證真正的貓條袋與湯匙弧度**。湯匙柄與匙頭交界約 x=142mm，而新前緣 x=146mm，仍應先以真實湯匙測試是否碰撞。

建議先印 1.2mm 標準滑塊；若袋子卡住、發白、皺折、破損，停止並改試 1.6mm。0.9mm 並非越緊越好。無法僅以間隙數據保證殘留減少程度，需以同款貓條實測比較。避免列印件接觸肉泥或貓口。
