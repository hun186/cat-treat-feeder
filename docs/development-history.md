# V1.0～V1.14 開發歷程（由當時交付紀錄歸檔）

| 版次 | 主要修正與實驗 |
|---|---|
| V1.0 | 首版本體、可滑動擠壓器與雙點式湯匙固定；尚無實物柄寬 |
| V1.1 | 依手量 9–14 mm 寬、約 6 mm 厚調整前後卡扣 |
| V1.2 | 後端由 15.2 mm 縮至 13.2 mm |
| V1.3 | 後端修正為 13.5 mm |
| V1.4 | 前端嘗試縮至 9.0 mm |
| V1.5 | 前端調為 9.5 mm；拆卸阻力仍需驗證 |
| V1.6 | 入口雙向斜面，改善易進難出的倒鉤 |
| V1.7 | 最寬→最窄量測 55 mm，第一次改間距 |
| V1.8 | 重新量測最寬點在尾端 35 mm、最窄點 87 mm；修正間距 52 mm |
| V1.9 | 前端卡扣側壁根部折斷，改無倒鉤開放導槽 |
| V1.10 | 前導槽從 10.8 改 10.0 mm，並加厚側壁根部 |
| V1.11 | 前導槽調回 9.5 mm，後端基座比照前端補強 |
| V1.12 | 發現左右滑軌位置不對稱，修正幾何定位與滑塊干涉 |
| V1.13 | 前端仍會滑脫，恢復淺倒鉤，入口 8.7 mm；基座保留補強 |
| V1.14 | 前端擋板與底板切面齊平，減少立式列印的局部不必要支撐 |

版本檔案的 Git 提交若是在 2026-11-04 整理時建立，屬於**依歷史成果重建的歸檔記錄**，不是宣稱各版本當時就曾提交至 GitHub。歷史實體驗證只涵蓋使用者實際回報的試印問題；CAD 封閉網格和干涉檢查不等於完整實物驗收。
