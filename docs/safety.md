# 衛生與安全界線

**本專案仍是未經實體完整驗收的工程原型，不是食安／獸醫／醫療認證產品。**

- 3D 列印零件避免直接接觸貓條、貓口或舔食區；商用 PP 匙的食品接觸合規性以實物標示與廠商資料為準。
- 使用前先試卡扣與滑塊；有應力發白、裂痕、過緊、鬆脫或斷裂即停用。貓咪可能咬裂湯匙，兒童操作需成年人監督。
- 依每隻貓提供獨立乾淨的食匙；跨場域多貓餵食應優先未用過的新匙。**同一支湯匙不要在不同貓之間直接共用**。
- 一般餐廳 PP 圓匙用餐後洗淨、沖淨、晾乾，可以保留給貓使用，但**洗淨不等於已消毒或無菌**，且尺寸需相容。
- 若 3D 列印本體或手沾有唾液，換匙仍無法消除所有污染途徑；應按場域規定清潔和適當消毒。
- 防疫主要針對貓與貓間透過共用食器的間接傳播；人貓仍有部分共通病原，不能宣稱人與貓完全不會相互傳染。
- 環境中的 FCV／FPV 傳播不能只靠替換食匙徹底阻斷；仍須重視手部衛生、器具清潔消毒與場域規定。
