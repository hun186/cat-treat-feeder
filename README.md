# 貓條餵食器｜Cat Treat Feeder

**可重複使用的 3D 列印貓條擠壓器，搭配可快速替換的食品接觸用 PP 湯匙。** 針對 15.5 cm 大圓匙設計，讓肉泥直接落入替換匙，並保留每隻貓換一支湯匙的衛生流程。

> **狀態：工程原型，非量產／安全認證產品。** 目前最新 CAD 版本 **V1.14**。已進行軟體幾何檢查；尺寸、公差、彈性夾持、實際耐用度、清潔及與貓咪的安全距離仍需實物驗證。

## 快速開始

1. 先查看 [`docs/measurements.md`](docs/measurements.md) 的湯匙實測位置，確認你的湯匙是否同款。
2. 先列印 [`current/front_snap_coupon_9p5_mouth8p7.stl`](current/front_snap_coupon_9p5_mouth8p7.stl) 與 [`current/two_point_52mm_front_snap.stl`](current/two_point_52mm_front_snap.stl)，不要硬壓或扭轉卡扣。
3. 再列印 [`current/base_body_v1_14_front_flush.stl`](current/base_body_v1_14_front_flush.stl) 及 [`current/squeeze_slider_v1_14.stl`](current/squeeze_slider_v1_14.stl)。
4. 在切片器檢查**直立擺放、前端擋板共面、支撐預覽與軌道間隙**；實物先空載試推，確認不卡滯，再嘗試肉泥擠出。
5. 依照 [`docs/printing-and-fit.md`](docs/printing-and-fit.md) 的順序完成試裝。

## 跟常見貓條餵食器相比

| 方案 | 優點 | 缺點／注意 |
|---|---|---|
| 商購約 NT$30 餵食器 | 便宜、容易購買、不需 CAD／列印 | 前端若在不同貓間重複接觸口水，需要完整清潔／適當消毒；跨貓群難維持一致換匙流程 |
| 3D 列印一體式餵食頭 | 能自由客製外形，不需外購前端食匙 | 列印層紋與細縫、噴嘴及列印環境、材質及清潔消毒適用性皆需評估，不能預設符合食品接觸要求 |
| 本專案：列印本體＋可換商用 PP 食匙 | 前端接觸件可針對每隻貓快速換匙、減少直接使用列印件承接肉泥；日常餐廳湯匙也可能適配 | 需尺寸吻合的 PP 大圓匙、3D 列印及調整技術；可能增加一次性耗材；仍需防止本體污染、卡扣斷裂 |

**重點不是宣稱「清洗後共用一定會傳染」**，而是讓不同場域／不同貓群餵食時，能用簡單一致的 SOP 降低一項可避免的接觸風險。

## 湯匙取得方式：採購或餐後留用

這款是**日常可能在餐廳提供的 PP 大圓匙**，不是專用的特殊貓咪湯匙。符合規格的餐廳塑膠湯匙，也有機會直接搭配本機使用；**相同長度不代表相容**，必須檢查局部匙柄厚度、寬度、弧度及雙卡扣位置。

- **購買新匙**：商品搜尋字詞「大圓匙 大叉匙 100入/包 塑膠湯匙 免洗餐具 塑膠餐具 甜品湯匙 餐廚用品 圓匙 湯匙 走道G」，請選「大圓匙」（不是叉匙）。[蝦皮商品頁](https://shopee.tw/%E5%A4%A7%E5%9C%93%E5%8C%99-%E5%A4%A7%E5%8F%89%E5%8C%99-100%E5%85%A5-%E5%8C%85-%E5%A1%91%E8%86%A0%E6%B9%AF%E5%8C%99-%E5%85%8D%E6%B4%97%E9%A4%90%E5%85%B7-%E5%A1%91%E8%86%A0%E9%A4%90%E5%85%B7-%E7%94%9C%E5%93%81%E6%B9%AF%E5%8C%99-%E9%A4%90%E5%BB%9A%E7%94%A8%E5%93%81-%E5%9C%93%E5%8C%99-%E6%B9%AF%E5%8C%99-%E8%B5%B0%E9%81%93G-i.23853172.7164826243)。賣場標題有「100入／包」，過去實物包裝照片卻是「50 PCS／包」；購買前以當下選項、包裝為準。此連結只是來源範例，非唯一可用款式或品質認證。
- **餐後留用**：用餐時若拿到同形同尺寸、無裂損的 PP 大圓匙，可以洗碗精徹底清洗、清水沖淨、晾乾並妥善保存，再**第一次給貓咪**使用。不得將「洗淨」寫成「無菌／已消毒」，也要避開有裂紋、缺口、刮痕或殘留調味料／洗劑的餐具。
- **不同貓或跨貓群使用**：以每隻貓獨立乾淨食匙為原則，跨地區或多人貓群場合**優先使用未使用過的新匙**，並遵守現場 SOP。即使前端換匙，若共用本體、雙手或其他部分碰到唾液，仍需採取清潔／適當消毒措施。

主要防疫動機是減少 **貓與貓之間** 的間接接觸傳播；人貓可共享部分病原，不能說人貓之間完全沒有傳染風險。詳見 [`docs/spoon-sourcing-and-reuse.md`](docs/spoon-sourcing-and-reuse.md) 及 [`docs/safety.md`](docs/safety.md)。

## 安全與授權

- 每隻貓使用一支獨立準備、完整潔淨且適合食品接觸的湯匙；跨貓群場合優先採用未使用過的新匙；印製件不能直接接觸肉泥或貓咪舌頭，避免污染交叉傳播。
- 注意貓咪咬湯匙、零件破裂、兒童夾手、卡扣脫落的風險；未經實物驗證前不要直接用於餵食。
- 規格標示並不等同於產品法規或耐熱認證；以實物包裝與廠商證據為準。
- **此儲存庫暫未指定開源授權條款**；著作權與再利用許可需由專案所有者決定，不要推定自動開源。
