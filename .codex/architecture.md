# Architecture — CURRENT STATE

## 系統邊界
- 可重複使用：3D 列印 PETG 本體、可滑動擠壓滑塊、雙點湯匙柄卡扣。
- 可替換接觸件：市售／餐廳常見的 PP 大圓匙，作為直接承接肉泥與貓舌的部位。
- 外部輸入：軟包裝貓條、人手推動；外部輸出：位於湯匙中的肉泥。

## 元件與資料流
1. 依 `docs/measurements.md` 選用／確認尺寸相符湯匙。
2. 輕壓 PP 匙柄至後端 13.5 mm、前端 9.5 mm 兩個卡扣；中心距 52 mm。
3. 放置貓條軟袋，從後方推動滑塊，把肉泥擠至匙面。
4. 每隻貓使用獨立乾淨食匙；跨貓群優先未用過的新匙。
5. 有唾液污染時，對共用本體與手部採取必要清潔及消毒。

## CAD/模型結構
- 單一 OpenSCAD 參數化模型，藉由 `part` selector 輸出底座、滑塊與試片。
- ASCII STL 是固定尺寸的產物；SCAD 才是可調整的權威模型。
- `scripts/validate_stl.py` 僅檢查基本拓樸幾何，不評估疲勞、滑動摩擦、食安或安全。
- `docs/development-history.md` 保存過去實驗與修復脈絡，不是目前尺寸權威。

## 不變條件
- 左右軌道必須對稱；滑塊與本體各行程位置不得干涉。
- 卡扣鬆緊需支持免工具換匙，不能靠過度壓入或扭轉解鎖。
- 3D 列印零件不得被設計為貓咪口部或肉泥的正常接觸面。
- 尺寸更改須先試片，再列印整機。
